# متجر MA Professional Perfume

## النشر (Vercel + Turso)
1. **Turso:** اعمل حساب على turso.tech وأنشئ قاعدة بيانات. انسخ **Database URL** (بيبدأ بـ libsql://) واعمل **Token** وانسخه.
2. **GitHub:** ارفع محتوى المجلد ده كله في repository **Private**.
3. **Vercel:** اعمل مشروع جديد من الـ repository. من Settings ← Environment Variables ضيف:
   - `TURSO_DATABASE_URL` = رابط القاعدة
   - `TURSO_AUTH_TOKEN` = الـ Token
4. اعمل Deploy (أو Redeploy لو المشروع موجود بالفعل).

## الأدمن
- الدخول من تاب «أدمن» في نافذة تسجيل الدخول. الموبايل: `01284993980` وكلمة السر: `HODA`.
- حساب الأدمن بيتعمل أوتوماتيك أول مرة الموقع يتصل بقاعدة البيانات.
- تقدر تغيّر كلمة السر من تبويب «حسابي» في اللوحة.
- (اختياري) تقدر تغيّر بيانات الأدمن الأولية بالمتغيرات `ADMIN_PHONE` و`ADMIN_PASSWORD` قبل أول تشغيل.
