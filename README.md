# متجر MA Professional Perfume — نسخة Vercel (سوداء ذهبية)

الموقع على Vercel، وقاعدة البيانات على Turso (SQLite على السحابة). الأدمن بيتعمل أوتوماتيك من المتغيرات أول مرة.

## الخطوات
1. **Turso:** اعمل حساب على turso.tech، وأنشئ قاعدة بيانات جديدة. من صفحتها خد **Database URL** (بيبدأ بـ libsql://) واعمل **Token** وانسخه.
2. **GitHub:** ارفع محتوى المجلد ده كله في repository **Private**.
3. **Vercel:** Add New → Project → اختار الـ repository. سيب الإعدادات زي ما هي، وقبل Deploy افتح Environment Variables وضيف:
   - `TURSO_DATABASE_URL` = رابط القاعدة
   - `TURSO_AUTH_TOKEN` = الـ Token
   - `ADMIN_PHONE` = رقم موبايل الأدمن
   - `ADMIN_PASSWORD` = كلمة سر قوية (6 حروف أو أكتر)
   - (اختياري) أرقام التواصل والدفع متحطة جاهزة في الكود: واتساب 01030602998، محفظة 01030602998، إنستا باي 01224213116. لو عايز تغيّرهم من غير تعديل كود ضيف المتغيرات دي:
   - `STORE_WA` = رقم واتساب المتجر بصيغة دولية، مثال: 201143330686 (بيشغّل أزرار الواتساب)
   - `WALLET_NO` = رقم المحفظة الإلكترونية (اختياري)
   - `INSTAPAY` = حساب إنستا باي (اختياري)
4. دوس Deploy. المتجر على رابط Vercel، والأدمن على `/admin`.

## ملاحظات
- أول طلب بعد النشر بيعمل الجداول ويضيف العطور الـ 54 وحساب الأدمن، فممكن ياخد ثواني.
- لو حاجة ما اشتغلتش، افتح Vercel → المشروع → Logs وابعت لي الخطأ اللي ظاهر.
- غيّرت متغيرات الأدمن بعد أول تشغيل؟ ما بتأثرش. غيّر كلمة السر من قاعدة البيانات، أو احذف حساب الأدمن من Turso وأعد النشر.

## بعد النشر
- من `/admin` ← المنتجات والأسعار: ضيف أسعار العطور (10 / 30 / 50 مل) وصورهم.
- الميكس بيتحسب سعره من متوسط سعر العطرين حسب النسبة والحجم.

## الشعار
الشعار موجود جاهز في مجلد `public`: `logo.png` (الكامل، لشاشة الترحيب) و`logo-mark.png` (الدايرة بس، للهيدر والأيقونة والهيرو). لو عايز تغيّره استبدل الملفين بنفس الأسماء.
